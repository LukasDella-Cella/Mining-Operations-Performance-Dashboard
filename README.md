# Mining Operations Performance Dashboard

## Project Overview

The Mining Operations Performance Dashboard is a data analytics project designed to monitor and evaluate mining operational performance.

The project analyzes drilling productivity, equipment downtime, fuel consumption, maintenance activities, and operational efficiency.

It combines SQL, Python, and Power BI to transform operational data into meaningful insights that support data-driven decision-making.

## Business Problem

Mining operations require continuous monitoring to maintain productivity, control operational costs, and improve equipment utilization.

This project addresses the need for a centralized analytical solution to:

- Monitor planned versus actual production.
- Identify equipment downtime patterns.
- Analyze fuel consumption.
- Compare drilling rig performance.
- Evaluate operational efficiency across mining sites.
- Support performance monitoring through interactive visualizations.

## Dataset Description

The dataset contains simulated mining operational records with the following characteristics:

- **360 records**
- **4 drilling rigs**
- **2 mining sites**
- **90 days of operational data**
- **11 columns**

The dataset includes operational information such as:

- Rig identification
- Operator identification
- Mining site identification
- Planned meters
- Actual meters
- Downtime hours
- Fuel consumption
- Maintenance indicators

## Key Performance Indicators (KPIs)

The dashboard includes the following indicators:

- Total Planned Meters
- Total Actual Meters
- Total Downtime Hours
- Total Fuel Consumption
- Achievement Rate

### Achievement Rate

The achievement rate measures actual production against planned production.

**Formula:**

Achievement Rate = (Actual Meters / Planned Meters) × 100
